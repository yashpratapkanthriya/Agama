Platform Architecture & Operations

Agama is an enterprise-grade local-first zero-backend speed reading system. PDF layout parsing, vector indexing (sqlite-vec), and ONNX token complexity inference run inside an embedded Rust core process.
⚡ Core Non-Functional Targets (NFRs)
  • FFI Transfer Latency: < 0.8 ms via flutter_rust_bridge v2 zero-copy stream sinks.
  • Vector Search Latency: < 4.5 ms over 20,000 document chunk embeddings.
  • Privacy & Encryption: 256-bit AES SQLCipher encryption with zero external network telemetry.
  • Data Historization: 17-character histvon/histbis temporal primary keys for zero data loss.
